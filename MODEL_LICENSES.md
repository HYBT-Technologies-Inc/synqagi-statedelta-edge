# Model Licences

No third-party model weights are included in this bootstrap repository.

Before adding a base model, fine-tuned checkpoint, quantized engine, tokenizer, or embedding model, record:

- model name and exact revision or commit hash;
- source URL;
- model-card URL;
- licence identifier and full licence text location;
- whether redistribution of weights is permitted;
- whether derivative fine-tuned weights may be redistributed;
- any acceptable-use or field-of-use restrictions;
- tokenizer and auxiliary asset licences.

A model must not be included in a public release until this file and `THIRD_PARTY_NOTICES.md` are updated.
