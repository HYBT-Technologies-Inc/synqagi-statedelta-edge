# Security Policy

## Supported Versions

Security fixes are provided for the latest tagged release and the current `main` branch during active development.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in public issues when they may expose devices, credentials, private data, model weights, safety controls, or deployment infrastructure.

Report the issue privately through the official security contact channel of AISC TECHNOLOGIES LTD or HYBT Technologies. Include:

- affected version or commit;
- reproducible steps;
- impact assessment;
- logs or evidence with secrets removed;
- proposed mitigation, if available.

## Safety Boundary

The language or decision model is advisory. Physical execution must pass through deterministic policy and safety validation. Hard safety limits must not be overridable by model output.
